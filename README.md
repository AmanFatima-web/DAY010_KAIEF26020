**✨ Features**

- 🔢 Sentence Embeddings
- 🗄️ FAISS Vector Database
- 📐 Cosine Similarity
- 🤖 Gemini LLM
- 🛡️ Input Safety Filtering
- 🔐 Output Safety Filtering
- ⚔️ AI Red Teaming

**Tech Stack**

`Python` `FAISS` `Sentence Transformers` `Gemini` `RAG`
